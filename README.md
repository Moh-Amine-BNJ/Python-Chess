# Python-Chess

A chess engine i made with pygame featuring **all the special rules**, **chess notations**, and **the ability to undo your move**.

---

## Features

- chess move notations
- undoing your move
- choosing wether to flip the board or not for pass-and-play
- king checks
- checkmate and stalemate
- castling
- pawn promotion
- en passant

## Requirements

Make sure to have Python installed with the following library: pygame  
You can install PyGame using this command:

```bash
pip install pygame
